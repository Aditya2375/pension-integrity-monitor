# V5 independent-validation candidate

Frozen model inference uses a data-only JSON tree model with mandatory expected digest from trusted run configuration. No uploaded pickle models are accepted. Intermediate aggregate pickle files remain local experimental artifacts; the production extraction path is not yet safe for arbitrary uploads. Do not expose this research runner as an upload API.

Training covers independent missing feeds, report delays, lower-volume ordinary living activity, missed certificates, historic certificates, stopped payments, account reuse and heavier household sharing. Monthly work/LPG observations are reduced to the latest record before matching. Pure scoring features are separate from names and target labels. No blind records or labels are training input. Scores remain review priorities, not calibrated death probabilities. Fixed operating point maps to0.5; no payment actions are available.

Fresh reporting-delay development evaluation:98.69% precision and96.24% recall. This misses98/98. Development results do not establish government-data performance. The next blind round is required, and all-scheme, coverage-aware production and population-scale validation remain open.
